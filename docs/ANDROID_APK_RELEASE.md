# Финальный результат Budget: APK для Android

**Обязательное требование:** после завершения работы над всеми разделами Budget предоставить **готовый установочный APK-файл**, а не только URL, PWA, исходники или AAB.

## Состояние на итерации №69 (2026-11-23)

- [x] В репозитории есть конфигурация Capacitor и зависимости Capacitor Android. Доступны команды cap:sync и cap:android.
- [ ] Файлы нативного Android-проекта не найдены по проверенным путям android/gradlew, android/app/build.gradle, android/app/src/main/AndroidManifest.xml. Перед сборкой повторно проверить структуру репозитория.
- [ ] Подготовить Android-проект и настроить совместимые версии JDK, Android SDK и Gradle.
- [ ] Синхронизировать собранный веб-код с Capacitor Android.
- [ ] Получить реальный устанавливаемый файл с расширением .apk. Отдельный .aab не считается выполнением этого требования.
- [ ] При необходимости распространения вне отладки создать подписанный release APK. Ключ подписи и пароли должны оставаться под контролем пользователя, не публиковаться в Git.
- [ ] Фактически установить APK на Android-устройство, проверить запуск и работу после повторного запуска.
- [ ] Проверить вход, совместную работу двух членов семьи, CRUD финансовых операций, банковский импорт, навигацию, прокрутку, клавиатуру, системную кнопку «Назад», сохранение данных и ошибки сети.
- [ ] По возможности проверить устройство Xiaomi 11T Pro пользователя. Сборка Gradle или эмулятор сами по себе не доказывают работоспособность на телефоне.
- [ ] Передать пользователю фактический APK, его версию, SHA-256, Git SHA и отчёт об установке/проверке.

## Когда выполнять

**После завершения разработки всех разделов проекта**, а не в конце отдельной итерации №69 или раздела «Бюджет». Подготовительные настройки допустимы раньше. Финальное завершение не объявлять, пока APK не собран и не передан.

## Контрольный ID реестра

**REL-ANDROID-APK-01 — итоговый APK для Android.** Статус [ ] до создания настоящего файла, подтверждённой установки и проверки основных сценариев. Если сборка состоялась, но установка не проверена — [~]. PWA, AAB и документация не закрывают пункт.

Проверку Safari/iOS/PWA учитывать отдельно, не подменяя ими Android APK.
