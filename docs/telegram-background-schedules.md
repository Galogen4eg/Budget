# Отложенные Telegram-напоминания Budget

## Как устроено

Веб-приложение отправляет снимок семейного календаря на `/api/calendar-telegram-sync` после явного включения Telegram-напоминаний и при изменении календаря. Сервер сверяет подписчиков семьи и регистрирует **разовые** задания через Vercel Schedules. Каждое задание публикует сообщение в частную очередь `budget-calendar-telegram-reminders`; обработчик `api/calendar-telegram-run.js` вызывается Vercel без открытой вкладки браузера.

После отправки напоминания о повторяющемся событии планируется следующее в серии. При переносе/удалении события старый запуск отменяется. Для обоих членов семьи используется их собственный Telegram Chat ID и часовой пояс, при этом приватные события фильтруются по исполнителю. Оплаченные обязательные платежи игнорируются. Финансовые транзакции никогда не создаются.

Дубликаты ограничиваются Redis-ключом доставки. Уведомления имеют семантику **at least once**, полной гарантии доставки/отсутствия дублей нет.

## Инфраструктура

- Firebase Spark, Firebase Auth и существующий Firestore: без изменений
- Redis/Upstash в существующем Vercel-проекте: хранение календарного снимка, зашифрованного Telegram-токена и состояния расписания
- `CRON_SECRET` из текущих production-настроек Vercel: производный ключ AES-256-GCM
- `@vercel/schedules` и `@vercel/queue`: разовые задания и закрытый обработчик, **без периодического cron**
- Лимит бесплатного Vercel Hobby по состоянию на ноябрь 2026: 500 созданий schedules и 5000 выполнений в месяц, общий на проект

Создание и обновление напоминаний проверяется по Firebase ID Token и фактическому членству пользователя в семье. Токены Telegram не помещаются в payload Vercel Queue и не пишутся в логи.

## Проверка после развёртывания

1. В Budget → Планы включить `Telegram: выкл.`, предварительно убедившись в корректных Chat ID и токене бота.
2. Создать событие на 10–15 минут вперёд и задать напоминание за 5 минут. Проверить в Vercel → Schedules разовое задание.
3. Полностью закрыть Budget и проверить, пришло ли сообщение в Telegram вовремя.
4. Перенести событие и затем удалить его, убедившись, что предыдущий запуск отменён.
5. Создать повторяющееся событие и проверить автоматическое создание следующего задания после первого сообщения.
6. Второму члену семьи изменить общее событие; проверить обновление расписания обоих участников.
7. Отключить Telegram-напоминания в Budget и убедиться, что задания удалены.

## Известные ограничения

- Сервер создаёт ближайший запуск для каждого интервала оповещения, а не бесконечный набор на все годы вперёд.
- Необычные локальные часы при переводе на летнее время могут быть пропущены; требуется отдельная проверка часовых поясов семьи.
- Изменения Firestore, сделанные *вне открытого Budget* сторонней системой, не вызывают синхронизацию до следующего открытия Budget. Это особенно относится к Telegram-боту, который сейчас переносит команды в Firestore через веб-клиент.
- Vercel Schedules и Queues находятся в стадии beta; автоматические тесты не заменяют реальную проверку доставки.
- Нет платных Firebase Functions или дополнительного хостинга.
